# 🎮 DSFarmByFir

DSFarmByFir — это эмулятор запуска игр для фарма квестов в Discord, которому не нужно скачивать сами игры. 

Удобный интерфейс: ищешь игру через поиск, жмёшь «Запустить» и выбираешь время автозакрытия (по умолчанию 15 мин, рекомендую 16). 

Автор: BloodFireYTTW, комьюнити FireFun_1 🔥

---

## ⚠️ Важное примечание
Программа только эмулирует запуск игры. Сам квест в Discord (кнопку «Начать задание») нужно активировать вручную в интерфейсе Discord перед тем, как запускать эмулятор.

---

## 🚀 Как запустить
1. Активируй нужный квест в Discord.
2. Скачай и распакуй папку с программой.
3. Запусти файл DSFarm.exe.
4. В открывшемся окне найди нужную игру через поиск.
5. Нажми кнопку «Запустить» и выбери время, через которое эмулятор закроется (советую ставить **16 минут**).
6. Фарми награды, не качая игры!

## 📁 Что где лежит
* Папка Farm — здесь хранятся все игры и пути к ним.
* DSFarm.exe — основной файл для запуска программы.
* Rebuild.bat — файл для восстановления (см. ниже).

## 🛠 Если программа забагалась
Если интерфейс завис, не запускается или выдает ошибку:
1. Закрой программу.
2. Запусти файл Rebuild.bat, который лежит в папке с программой.
